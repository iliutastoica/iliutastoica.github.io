01 · Intent

Goals and constraints

Keep knowledge useful across changing sources while preserving the context needed to review each signal.

  • Retain source context as documentation changes.
  • Route meaningful signals through explicit processing stages.
  • Make retrieved knowledge reviewable before reuse.

02 · Design

Decisions that shape the interface

Normalize before retrieval

A shared document representation makes retrieval context easier to reason about across varied source formats.

Route events explicitly

Separate arrival of a signal from the processing and knowledge update it may trigger.

Keep governance visible

Source context and review boundaries guide how captured knowledge enters retrieval and memory.
