01 · Intent

Goals and constraints

Help people understand an initiative and find a useful way to participate.

  • Explain an initiative before asking for participation.
  • Make resource needs and checklist progress readable.
  • Keep data loading and route transitions explicit.

02 · Design

Decisions that shape the interface

Organize around participation

Discovery, resource needs, and volunteer choices define the main application journey.

Separate server and route state

Query and routing tools support distinct data-loading and navigation responsibilities.

Keep identity at an integration boundary

The frontend meets Microsoft Entra ID through a defined integration context.

03 · Implementation
